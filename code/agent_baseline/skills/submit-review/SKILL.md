# Submit review

Check these before you call submit the final time:
1. The handle is your complete answer, not a partial candidate.
2. Components answered no that you keep: you can say why for each large one.
3. Components answered yes that you dropped: the report lists them. Each drop has a reason, or you bring it back with `add_region`.
4. Removed pixels were not counted as corrected errors.
5. The summary describes the submitted mask and states where you went against the verifier.

If nothing changed in the image pair, submit `empty`, and say so.
