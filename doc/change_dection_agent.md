# 交接：变化检测 agent 摸底实验

## 背景（已定，不需要重新讨论）
- 课题：在现有遥感变化检测器的输出上做改进，最终形态是一个"召回优先"的变化检测 agent：检测器掩码只是先验，agent 负责补漏检和确认变化。导师要求：不能放过漏检。
- 之前的原型：固定程序在掩码上选对象和点，MLLM 只决定是否调用 SAM3；工具箱里还有 SimpleClick，效果一般。这个原型不再沿用，只作参考。
- 现阶段不训练 agent。先用下面三个实验量出"改进空间在哪里"，再决定主攻方向。

## 第 0 步：先在服务器上确认这些（动手前把结果写进 `results/env.md`）
- 代码：之前原型的仓库路径、入口脚本、SAM3 和 SimpleClick 的调用方式。
- 数据：LEVIR-CD、WHU-CD 的路径和划分（用 test 集）；影像尺寸、是否已切块。
- 检测器：现有哪些检测器的预测结果或权重（目标 2–3 个，例如 BIT、ChangeFormer 或服务器上已有的）；输出是二值掩码还是概率图。没有概率图的，记下来，第 1、3 实验里的阈值扫描会受影响。
- 模型：SAM3 权重；可用的 MLLM（如 Qwen-VL 系列）及显存是否够。
- 缺了任何一项就停下来报告，不要自己下载大模型或换数据集。

## 实验 1：误差分解（优先做）
目的：看检测器的错误主要是哪一类，决定主攻精度侧还是召回侧。
- 输入：每个检测器在 test 集上的预测掩码 + 真值。
- 目标级匹配：对预测和真值分别取 8 连通域；一个真值目标和任一预测目标 IoU ≥ 0.5 记为命中。
  - 整目标漏检（FN 目标）：真值目标没有任何预测像素覆盖，或最佳 IoU < 0.1。
  - 部分命中：0.1 ≤ 最佳 IoU < 0.5，单列一类。
  - 整目标误检（FP 目标）：预测目标与所有真值 IoU < 0.1。
  - 边界误差：命中目标内部的 FP + FN 像素。
- 同时统计：像素级 F1/IoU；三类误差各占总误差像素的比例；按目标面积分桶（如 <100、100–1000、>1000 像素）的漏检率。
- 有概率图的，再扫 3–5 个阈值，看降阈值能补回多少漏检、代价是多少误检。
- 输出：`results/exp1_error_breakdown.md`（表格 + 一段结论），以及每类误差各 5 个可视化样例（t1、t2、真值、预测叠加）。

## 实验 2：SAM3 oracle 上界
目的：假如提示是完美的，SAM3 最多能把 F1 提多少。上界很低的那一侧就不值得做 agent。
- 2a 精度侧：对每个命中目标，用真值目标的外接框（或框 + 真值内的 1 个正点）提示 SAM3，替换原预测，算 F1 变化。
- 2b 召回侧：对每个整目标漏检，用真值框提示 SAM3 补上，算 F1 变化。
- 时相选择：SAM3 是单时相分割。新建类（t2 有、t1 无）喂 t2，拆除类喂 t1；判断不了类型的两个都跑，取 IoU 高的，并记录各自的结果。
- 小目标先按框外扩一定比例裁块再送 SAM3，记录用的外扩比例。
- 输出：`results/exp2_oracle.md`，四个数：原始 F1、2a 后、2b 后、两者都做后。

## 实验 3：MLLM 能否判断"是不是真变化"
目的：决定 MLLM 能不能当验证者。
- 候选：实验 1 里的命中目标（正样本）和 FP 目标（负样本），再加降阈值后新出现的区域；各抽 200 个左右，正负平衡。
- 输入给 MLLM：候选区域外扩后的 t1、t2 裁块（可加框标注），问是否是真实变化，要求输出是/否和置信度。
- 对比：检测器自身在该区域的平均置信度（有概率图时）。指标用 AUC 和固定阈值下的准确率。
- 输出：`results/exp3_mllm_verify.md`，附 10 个 MLLM 判错的样例。

## 可以自己判断的
阈值扫描的具体取值、裁块外扩比例、MLLM 的 prompt 写法、可视化样式、脚本组织方式。

## 不要做的
- 不训练任何模型，不改检测器。
- 不实现完整 agent 流程，不复现论文方法。
- 改了上面的判定标准（如 IoU 阈值）要在结果文件里写明原因。

## 交付
三个结果文件 + `results/env.md`，最后写一页 `results/summary.md`：哪类误差占大头，精度侧和召回侧的上界各是多少，MLLM 能否胜任验证。
