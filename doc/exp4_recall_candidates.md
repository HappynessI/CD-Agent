# 任务：实验 4，召回侧的候选生成与确认

给服务器上的 Claude。前置结果见 `results/summary.md`（实验 1–3），本任务沿用 `code/probe/` 的代码组织、目标匹配口径和 `run.sbatch` 运行方式。

## 背景（已定，不需要重新讨论）
- 实验 1–3 的结论：主攻召回侧；主要评测场景是 SECOND（多类语义变化），SYSU-CD 作对照，LEVIR/WHU 暂不做。精度侧暂时搁置。
- SECOND 上补齐整目标漏检的上界是 +7.8 F1，但它假设漏检位置和框都是完美的。检测器对这些漏检几乎没有信号，降阈值无效。
- 所以本实验回答两个问题：
  1. **找**：有哪些候选来源能覆盖检测器的漏检，代价是多少假候选？
  2. **确认**：在真实候选（而不是随机框）上，什么信号能区分真变化和伪变化？
  最后用"找 + 确认 + SAM3 补全"估一个不靠真值的真实 F1 增益，和 +7.8 的上界对照。

## 口径
- 检测器：SECOND 用 MambaSCD-Base，SYSU 用 SChanger-small（与实验 1–3 一致）。
- 目标漏检集合 M：实验 1 定义的**无信号漏检**（检测器预测覆盖目标像素 < 10%），只取面积 ≥ 20 px 的目标。部分命中目标的缺失部分单列为 M_partial，作为次要统计。SECOND 的真值目标沿用按（t1 类别，t2 类别）拆分后的连通域。
- 候选：一个连通区域或一个框，带一个排序分数。只统计**不与检测器 0.5 预测重叠超过 50%** 的候选（已被检测到的区域不算召回候选）。
- 覆盖：一个漏检目标被某候选覆盖，指候选覆盖了该目标 ≥ 50% 的像素，且候选面积不超过目标外接框面积的 4 倍（防止大块候选"什么都覆盖"）。如需改阈值，在结果里写明原因。
- **真值只用于评估。** SECOND 的语义标签只在变化区域有值（0 = 未变化），不能拿真值语义图做候选来源，否则是泄漏。

## 第 0 步：确认可用资源（写进 `results/env.md` 的新小节）
- MambaSCD-Base 的两期语义头输出（t1、t2 的 6 类语义图）是否已保存；没有的话，用官方权重补跑 SECOND test 的语义输出。
- 服务器上是否有独立的地物分类 / 语义分割模型（不是 MambaSCD）；没有就用 SAM3 文本提示代替（见来源 B）。
- 可用于提取图像特征的编码器：SAM3 的图像编码器一定有；其他（如 DINOv2）有就记下来。
- AnyChange 的代码或权重是否在服务器上。**不在就不要下载**，用来源 D 的自实现代替。
- 缺资源时停下来报告，不要自己下载大模型或换数据集。

## 实验 4a：候选来源的覆盖率（先做）
对 SECOND 全部 test（SYSU 全部 test 作对照）跑下列来源，每个来源单独产出候选和分数：

| 编号 | 来源 | 做法 | 分数 |
|---|---|---|---|
| A | 检测器语义头做差 | MambaSCD 的 t1、t2 语义图类别不同的像素，取连通域 | 区域内两期类别概率差的均值 |
| B | 独立语义分割做差 | SAM3 文本提示分别分割两期的 SECOND 六类（不透水地面、树、低矮植被、水体、建筑、运动场），每像素取最高分类别，两期类别不同处取连通域 | 两期类别置信度乘积 |
| C | 建筑实例差 | SAM3 "building" 两期实例，匹配 IoU < 0.5 的实例（新建、拆除），以及匹配但外观差异大的实例（用于改建：同位置建筑，实例内两期编码器特征余弦距离高） | 1 − 匹配 IoU，或特征距离 |
| D | 编码器特征差 | SAM3 编码器两期 patch 特征的余弦距离，按图像内分位数（如前 5%、10%、20%）阈值化取连通域 | 区域内平均距离 |
| E | 同类变化检索 | 用检测器在同一张图上高置信的变化目标（概率 > 0.9）作为样例，取其 t1、t2 特征拼接向量，在全图检索相似区域；没有高置信样例的图跳过并记录比例 | 与最近样例的相似度 |
| F | 网格扫描（基线） | 把图切成固定大小的块（如 64 px，步长 32），每块都是候选 | 块内检测器概率均值 |
| G | 降阈值（基线） | 检测器概率 0.05 / 0.1 / 0.2 新增的连通域，复用实验 1 | 区域概率均值 |

统计（每个来源，以及 A–E 的两两并集和全部并集）：
- M 的覆盖率：按目标数和按像素，并按变化类型（t1 类别 → t2 类别，至少列出改建、植被相关、地表↔植被、新建建筑）和面积分桶拆开。
- 每张图的平均候选数、候选总面积占图像面积的比例。
- 候选纯度：候选与真值未检测变化重叠 ≥ 50% 的比例。
- 覆盖率–候选数曲线：按分数排序，取每张图前 k 个候选（k = 1, 3, 5, 10, 20, 全部）时的覆盖率。
- 输出：`results/exp4a_candidates.md`（表格 + 结论 + 每个来源 3 个覆盖成功、3 个漏掉的可视化样例，放 `figures/exp4a/`）。

## 实验 4b：在真实候选上的确认
- 候选池：取 4a 中覆盖率–候选数折中最好的 2 个来源（以及它们的并集），每个数据集抽约 300 个候选，按真值标注：区域内真值变化占比 ≥ 50% 为正，< 10% 为负，其余丢弃。负样本就是真实的伪变化，不再用随机框。
- 比较的信号：
  1. 检测器在区域内的平均概率；
  2. 候选来源自己的分数；
  3. 两期语义一致性（来源 A 或 B 的两期类别是否一致、置信度多高）；
  4. MLLM：百炼 qwen3.7-plus 和本地 Qwen3.5-4B，沿用实验 3 的通用变化提示词和裁块方式；
  5. 简单组合：以上信号做逻辑回归，5 折交叉验证（这是唯一允许的"训练"，不训练任何网络）。
- 指标：AUC（自助法 95% CI），以及召回率固定在 80% 和 90% 时的误检率。
- 输出：`results/exp4b_confirm.md`，附 10 个判错样例（`results/exp4b_error_examples/`）。

## 实验 4c：不靠真值的端到端估计
- 流程：4a 选出的来源 → 4b 最好的确认信号（阈值在验证折上选，使召回率约 80%）→ 对确认通过的候选用其外接框提示 SAM3（沿用实验 2 的裁块方式；时相选择用来源给出的变化方向，判断不了时两期都跑取置信度高者）→ 把结果并入检测器掩码。
- 报告 SECOND 和 SYSU 上的像素级 F1 变化，并和实验 2 的 2b 上界（SECOND +7.81）对照；同时报告补进来的误检像素。
- 输出：`results/exp4c_end_to_end.md`。
