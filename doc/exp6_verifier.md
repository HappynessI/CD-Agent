# 任务：实验 6，训练漏检验证器，并检验泛化性

给服务器上的 Claude。前置结果见 `results/summary.md` 中"实验 4""实验 5"两节。本任务沿用 `code/probe/` 的代码组织、口径和运行方式。**这是第一个允许训练模型的实验**，允许训练的范围见"训练许可"。

## 背景（已定，不需要重新讨论）
- 课题定位：给**任意已训练的变化检测器**做召回补漏的即插即用模块。检测器只是被改进对象，不是方法的一部分。
- 流水线已经由实验 4–5 定型：
  1. **找**：候选来源 H1（原版 AnyChange）、B（SAM3 六类做差）、G0.05（检测器概率 > 0.05 的新增区域）、C（建筑实例差）。
  2. **切细**：大候选用 SLIC 超像素切成小块（参数同实验 5c）。
  3. **确认**：本实验要训练的**切块级漏检验证器**。
  4. **补全**：确认通过的切块直接并入检测器的 0.5 掩码，不用 SAM3。
- 实验 5 的结论：确认完美时 SECOND 能拿到 +6.96～+8.50 F1，但零样本信号（检测器概率、复检、语义一致性、RemoteCLIP、MLLM）都不够。并入区域的像素精度要高于当前 F1 的一半（SECOND 约 37%，SYSU 约 42%），F1 才会上升；现在最好约 20–29%。

## 训练许可
- 允许：按 6a 交叉拟合重训检测器（只用 SECOND train）；训练验证器（6b）。
- 不允许：用任何 test 集数据训练或调阈值；用真值语义图生成测试时的候选。
- 阈值、超参数都在 train 内划出的验证集上选，test 只跑一次最终评估。

## 第 0 步：资源确认（写进 `results/env.md` 的"实验 6 资源"一节）
1. SECOND train 的规模和标签；MambaSCD 官方训练代码和配置能否复现训练。
2. **再找一个 SECOND 上的检测器**（不同结构，有官方 SECOND 权重即可，例如其他语义变化检测模型）。允许下载其官方代码和权重。
3. 服务器上是否已有第三个带两期语义标签的变化检测数据集（如 HRSCD、Landsat-SCD）。**不要下载数据集**，没有就记下来。
4. 验证器骨干：AnyChange 已下载的 SAM ViT-H 编码器；卫星版 DINOv3（`facebook/dinov3-vitl16-pretrain-sat493m`，实验 4 时下载未完成，本次**允许补全下载**）；RemoteCLIP 视觉编码器（已有）。
5. RingMo-SAM、Zero-OVCD 的代码和权重是否公开可得（见 6d）。允许下载它们的官方代码和权重；拿不到就停下该子项并报告。
6. 估算 6a 交叉拟合重训的总耗时。**如果超过 3 天 GPU 时间，先停下报告**，附上缩短方案（如减少训练轮数、K=2）。

## 6a：构造训练候选池（交叉拟合）
- 问题：官方 MambaSCD 就在 SECOND train 上训练，在训练图上几乎不漏，直接在 train 上生成的候选与 test 分布完全不同。
- 做法：把 SECOND train 按图像分成 K=3 折。每次用其余两折重训 MambaSCD（官方配置，可按第 0 步的估算缩短），在留出折上推理，得到"没见过这张图的检测器"的输出。三折拼起来，就是整个 train 集的无偏检测结果。
- 在这些输出上跑完整的"找 + 切细"流水线（H1、B、G0.05、C，参数同实验 5），得到训练切块池。标签：切块内真值变化占比 ≥ 50% 为正，< 10% 为负，其余丢弃。
- 另保存每个切块的元数据：来源、面积、所在图像、检测器概率统计，以及两期真值类别（正样本才有）。
- **分布检查**（必须做）：对比交叉拟合候选池和 test 候选池的正例率、检测器概率分布、各来源占比、面积分布。如果差别明显，在结果里写明，并说明对后续结论的影响。
- 从 train 中按图像再划 10% 作验证集，用于选阈值和早停。
- 输出：`results/exp6a_pool.md`。

## 6b：训练验证器
三档，按顺序做，前一档完成并出结果后再做下一档：

**V1 小分类器（主力，必须做）**
- 输入：以切块为中心的 t1、t2 裁块（外扩方式同实验 5b 原尺寸复检）、切块掩码、检测器概率图裁块。
- 结构：冻结骨干分别提两期特征 → 在切块掩码内池化 → 拼接 [f1, f2, |f1−f2|, 检测器概率统计] → 2–3 层 MLP 输出 P(真变化)。
- 骨干对比：SAM ViT-H 编码器、卫星版 DINOv3、RemoteCLIP 视觉编码器，各训一个，选验证集最好的作主结果。
- 损失：按真实正例率加权的 BCE 或 focal loss（二选一，写明理由）；不做正负平衡下采样，保持真实分布。

**V2 MLLM 微调（对照，V1 完成后做）**
- 模型：本地 Qwen3.5-4B，LoRA 微调。
- V2a：只学答案（"是/否"）。
- V2b：学模板推理 + 答案。推理由 SECOND 两期语义标签自动生成，先说两期各是什么地物，再下结论。例：正样本"t1 为低矮植被，t2 为建筑，地物类别改变，是真实变化（新建）"；负样本"两期均为树，仅色调不同，不是真实变化"。负样本没有语义标签时，用"两期为同一地物"的通用模板，并统计这类样本占比。
- 训练集可以从 6a 池中按真实正例率抽一个子集（规模自己定，写明），评估仍在完整 test 池上做；如果全量推理太慢，可以在 test 上做分层抽样评估，写明抽样方式。

**V3 GRPO（可选）**：只有 V2b 明显好于 V2a 时才做。在 V2b 基础上以"答对"为奖励做 GRPO，参照实验地图中的 Seg-Zero 做法。

**评估（每档都做，在 SECOND test 候选池上）**
1. AUC，以及召回 80% / 90% 时的误检率（与实验 4b、5b 同口径，便于比较）。
2. 按真实正例率的像素精度：召回 80% 时，补入切块中真变化像素占比，与 F1/2 门槛对照。
3. **端到端**：用验证集选好的阈值，确认后直接并入，报告 F1、P、R、ΔF1、新增 TP / FP 像素，以及**目标级召回**（真值目标中被覆盖 ≥ 50% 的比例，按面积分桶）。对照实验 5c 的零样本最好结果（−0.73）和切块级 oracle（+6.96 / +8.50）。
- 输出：`results/exp6b_verifier.md`。

## 6c：泛化性检验（V1 最好的版本即可）
1. **换检测器**：用第 0 步找到的第二个 SECOND 检测器重跑"找 + 切细"。验证器分两种用法：直接用在 MambaSCD 候选上训练好的版本（不重训），以及在该检测器的交叉拟合候选上重训（如果第二个检测器的重训代价过高，只做前者并写明）。报告端到端 ΔF1。
2. **换数据集**：把 SECOND 上训练的验证器直接用在 SYSU test 上（候选生成同实验 5，检测器 SChanger-small），报告 AUC 和端到端 ΔF1。如果第 0 步有第三个语义变化数据集，同样做一遍。
3. **不伤好结果**：在 LEVIR 和 WHU 上用同样的流程（SECOND 训练的验证器、验证集选的阈值），报告 ΔF1。目标是不明显下降（如 ≥ −0.3）。
- 输出：`results/exp6c_generalization.md`。

## 6d：待办补测（来自项目待办清单）
1. **RingMo-SAM**：用它的类别识别生成两期地物图，替代 SAM3 六类，得到新的来源 B′。按实验 4a 口径测覆盖率、纯度、前 k 曲线，并和 B 比较；同时测"两期语义一致性"作为确认信号的 AUC（同 4b 样本）。如果 B′ 明显好于 B，在 V1 的训练池中用 B′ 替换 B 再训一次，报告变化。补全环节仍不用它。
2. **Zero-OVCD 第一阶段**（arXiv 2608.11663）：免训练，用 DINOv3 两期稠密特征相似度定位变化、SAM 出掩码、SegEarth-OV3 判类别。作为新候选来源 ZO，按 4a 口径测覆盖率、纯度、前 k 曲线，并和 H1、B 及并集比较。只取第一阶段，不训练它的第二阶段。方法细节以其论文和代码为准；没有公开代码就停下此项并报告。顺带：服务器已有 OmniOVCD，可作为 SAM3 两期实例做差的对照一并报告。
- 输出：`results/exp6d_backlog.md`。

## 6e：同一个验证器去误检（在 6b 的 V1 完成后做）
目的：检验"区域级校正"能否从只补漏扩展到"补漏 + 去误检"，用的是同一套切细和同一个验证器，不另训模型。
1. **去误检上界（oracle）**：在 SECOND、SYSU test 上，把检测器 0.5 掩码按连通域拆成预测区域，大区域用同样的 SLIC 切细。按真值把"切块内真变化占比 < 10%"的切块全部删掉，报告 F1、P、R、ΔF1、删掉的 TP / FP 像素。另报告"只删整目标误检（整个连通域与真值无交）"的上界，对照实验 1 的误差分解。
2. **验证器去误检**：用 V1 最好版本给这些预测切块打分，低于阈值的删掉。阈值在 train 验证集上选（交叉拟合检测器在验证集上的预测区域，同 6a 的切法和标签规则）。注意这里切块来自检测器自己的预测，分布和补漏候选不同：先直接用 6b 的模型；如果验证集上效果明显不好，再把交叉拟合得到的预测切块加进训练池重训一次，两种都报告。
3. **对照基线**：只用检测器自身概率（切块内平均概率）删块，阈值同样在验证集上选。实验 3 显示检测器给自己的预测打分已经很准（AUC 0.93–0.98），验证器要超过这个基线才算有用。
4. **合并**：补漏（6b 端到端）+ 去误检同时做，报告最终 F1、P、R、ΔF1 和目标级召回。
5. LEVIR、WHU 上跑同样的去误检流程，报告 ΔF1（不伤好结果，≥ −0.3）。
- 输出：`results/exp6e_fp_removal.md`。
