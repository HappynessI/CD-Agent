## 任务线一：T3 视觉示例检索（基于 `dev60`：`tune30` 选参，`confirm30` 冻结验证）

针对 N7 暴露的三大核心病灶（Top1 因示例自匹配导致 33/60 任务 0 TP、纯实例池漏掉地表转换、空目标样本无校准拒识），必须依次完成以下三步**干预实验**（不可只做统计审计）。

### Step T3-1：候选池示例自匹配硬剔除（必做干预实验）

在 `R1` 几何筛选后的候选池（分别测试 `delta` 和 `joint` 特征排序）进入 Top-K 截断之前，执行显式几何去重：

1. 对任意候选掩码 \(C\) 与给定同图示例掩码 \(E\)（仅针对同图 T3.1；跨图无此步），计算示例覆盖比：
   \[
   r_{\text{overlap}}=\frac{|C\cap E|}{|C|}
   \]
   以及交并比 \(\operatorname{IoU}(C,E)\)。
2. **硬剔除规则**：凡满足 \(r_{\text{overlap}}\ge 0.15\) 或 \(\operatorname{IoU}(C,E)\ge0.15\) 的候选，直接从候选列表中**彻底移除**；对保留但仍有微小交集（\(0<r_{\text{overlap}}<0.15\)）的候选，统一替换为扣除示例后的净区域 \(C\setminus E\)（若净面积小于 16 原生像素则一并移除）。
3. 在去重后的干净候选池上，重新评测 `Top1`、`Top3`、`Top5`、`Top8` 在 `tune30` 与 `confirm30` 上的表现，分开汇报非空任务 F1、剩余 GT ≥16 像素非空任务 F1、空目标总 FP 像素与空集正确率。

### Step T3-2：基于示例属性的“实例特征 vs 稠密概率”免训练分流

不要再用 VLM 猜文本词去调 `segment_text`。直接利用示例掩码 \(E\) 内部可观测属性，在 Step T3-1 的干净实例路线（`Branch-Inst`）与 SegEarth 七通道稠密转换路线（`routeA`，记为 `Branch-Dense`，同样需扣除示例区域 \(E\)）之间自动路由。

1. **计算示例可观测指标**（仅在 \(E\) 内部读取 SegEarth 前后时相概率与掩码几何）：
   - 设示例在 \(T_1,T_2\) 上的主导预测类别为 \(c_1,c_2\)，人工建筑/运动场类别集合为 \(\mathcal{O}_{\text{struct}}=\{\text{building},\text{playground}\}\)；
   - 计算示例掩码紧凑度（或边界框填充率）与面积。
2. **确定性路由规则**：
   - 若 \(c_1\in\mathcal{O}_{\text{struct}}\) 或 \(c_2\in\mathcal{O}_{\text{struct}}\)：走 `Branch-Inst`（去自匹配后的 `joint` 或 `delta` 路线，在 `tune30` 上选定二者之一后冻结）。
   - 否则（即两端均为植被、裸地、水体、树木等地表类）：走 `Branch-Dense`（`routeA` 稠密转换检索）。
3. 同步评测一种融合变体 `Branch-Hybrid`：在结构类任务上取 `Branch-Inst` 与高置信 `Branch-Dense` 的交/并集（在 `tune30` 确定最佳组合后，在 `confirm30` 上一次性冻结评估）。

### Step T3-3：图内相对显著性空集门控 + 证据增强核验

N7 已证明跨图固定原始余弦阈值未在现有确认池复现收益。改用**图内分布相对门控 + 少量高优候选核验**：

1. **图内相对门控**：对去自匹配后的候选特征得分序列 \(\{s_1,s_2,\ldots,s_N\}\)（\(s_1\) 为最高分），计算首候选相对背景候选池中位数/均值的显著性裕度，例如：
   \[
   z=\frac{s_1-\mu_{\text{bg}}}{\sigma_{\text{bg}}+\epsilon}
   \]
   以及首候选内部的 SegEarth 转换概率一致性得分 \(p_{\text{trans}}(C_1)\)。在 `tune30` 上用网格搜索标定联合拒识条件；不达标直接输出空掩码 \(\emptyset\)。
2. **证据卡片双图核验**：仅核验通过门控的前 \(K\le5\) 个候选。调用 VLM 核验示例双期裁剪图与候选双期裁剪图时，在 Prompt 中同步注入两行定量证据卡片，包含候选像素面积、与示例的特征余弦相似度、SegEarth 在示例与候选内部的 \(T_1\to T_2\) 主导类别概率。若全部送审候选被拒，最终输出空掩码 \(\emptyset\)。

## 任务线二：`find_missed` 主动补漏（基于 30 条记录：`tune15` 选参，`confirm15` 冻结验证）

严禁继续在原封不动的 `balanced V0@Top10` 旧表上只改外层掩码面积规则。必须从底层按以下三步重建受控补漏管线。

### Step FM-1：方向感知的候选源裁剪 + 边界膨胀扣除 + 语义概率差门控

1. **利用合法任务方向裁剪来源**（读取任务定义中的方向约束）：
   - 任务方向为 `demolish`（拆除）时：**硬性关闭 S3 与 S4**，仅合并 `S1 + S2 + S5(dino_020)`；
   - 任务方向为 `build`（新建）或 `any`（常规无方向建筑变化）时：启用 `S1 + S2 + S3 + S4 + S5(dino_020)`。
2. **膨胀扣除防伪碎斑**：将初始预测掩码 \(M_{\text{init}}\) 做半径 \(r=3\) 像素的形态学膨胀，得到 \(\operatorname{Dilate}(M_{\text{init}},3)\)，从所有候选区域中扣除该膨胀区；剔除两期分割边缘微偏造成的粘连碎斑（移除扣除后面积小于 25 像素的残片）。
3. **语义概率差物理门控**（针对高密度静态建筑误检）：
   - 利用已缓存的 SegEarth 建筑通道概率图 \(P_{\text{bldg}}^{(1)},P_{\text{bldg}}^{(2)}\)，计算候选连通域 \(C\) 的有向语义变化均值。
   - `build`：\(\Delta P(C)=\operatorname{mean}_{x\in C}(P_{\text{bldg}}^{(2)}(x)-P_{\text{bldg}}^{(1)}(x))\)。
   - `demolish`：\(\Delta P(C)=\operatorname{mean}_{x\in C}(P_{\text{bldg}}^{(1)}(x)-P_{\text{bldg}}^{(2)}(x))\)。
   - `any`：\(\Delta P(C)=\operatorname{mean}_{x\in C}|P_{\text{bldg}}^{(2)}(x)-P_{\text{bldg}}^{(1)}(x)|\)。
   - 在 `tune15` 上扫描阈值 \(\tau_{\text{sem}}\)，滤除 \(\Delta P(C)<\tau_{\text{sem}}\) 的静态伪变化候选，重点分析既有 DINO 门控未排除的静态建筑。

### Step FM-2：用“未覆盖区域图像变化残差”替代“当前掩码面积”做调用前触发器

N7 已证明“掩码面积小 = 漏检多”这一假设在现有池内不成立。改为计算**掩码外图像残差信号**：

1. 在膨胀掩码外部
   \[
   \Omega_{\text{out}}=\Omega\setminus\operatorname{Dilate}(M_{\text{init}},3)
   \]
   统计同时满足“方向性语义概率差 ≥ \(\tau_{\text{sem}}\)”且“DINOv2 特征差异 \(1-\cos\) 显著”的残差连通域总像素面积 \(A_{\text{res}}\) 及高置信残差块数量 \(N_{\text{res}}\)（或直接统计通过 Step FM-1 全部物理门控后的净剩余候选总数/面积）。
2. **触发规则**：若 Step FM-1 门控后净候选数为零，或残差证据强度低于 `tune15` 选定门限，则**不触发补漏**（零修改，直接返回 \(M_{\text{init}}\)）；仅在掩码外存在显著未解释变化残差时进入排序与 VLM 核验。
3. 重点检查 N7 的灾难坏例，例如 LEVIR `train_121`、SECOND 拆除 `train_1322`，记录新门控和源裁剪对新增 FP 的影响。

**接口计量说明**：残差计算可能本身需要候选生成或特征提取；如使用门控后的候选数作为信号，应分别报告“是否继续调用 VLM 核验”的触发率与“是否调用 `find_missed` 完整工具”的触发率，在方法报告中说明该信号属于调用前可直接取得，还是需要先运行候选生成/特征提取才能取得；不要求为此开展专项成本优化或精细计时。

### Step FM-3：定量证据增强核验（`V0 + Evidence`）与自适应 Top-K 截断

1. 对通过 Step FM-1 和 FM-2 的候选，按综合证据分（结合 \(\Delta P(C)\)、DINO 差异与有效面积，在 `tune15` 上锁定权重）取前 `K=5` 和 `K=10`。
2. 对缺少历史核验缓存的新入围候选，调用 `qwen3.7-flash` 补齐核验。比较原版 `V0` 与注入数值证据卡片的 `V0_evidence`：在原四图基础上，在文本中告知该区域像素面积、前后期 SegEarth 建筑概率均值 \(\bar P^{(1)}\to\bar P^{(2)}\) 与 DINO 差异值。

## 交付与验收硬性要求

1. **禁止只报 Pooled F1 掩盖分布差异**：
   - `find_missed` 必须同时输出：**15 任务 Pooled F1**、**15 任务 Macro 平均 F1**，以及**分任务组（LEVIR / SECOND 新建 / SECOND 拆除）各自的 F1 与新增 TP/FP 明细**。须区分“macro F1 水平”和“macro ΔF1”，不得混用。

2. **有条件自动推进在线小试**：
   - 若 Step FM-1～3 在 `confirm15` 上的 Pooled F1 与三组平均 F1 **同时高于“从不补漏”基线**，自动选取最优配置，跑此前准备好的 **6 任务 × 2 组 × 3 seeds** 真实在线 Agent 对照。
   - 若 Step T3-1～3 在 `confirm30` 上的非空子集 F1 高于原 `R1 Top8`（16.04），且空目标 FP 下降超过 50%，自动跑 **10 任务 × 2 组 × 3 seeds** 真实在线 T3 Agent 对照。
   - 若离线 `confirm` 未过上述红线，则停在离线阶段，输出前 10 个核心成败个案的可视化诊断，并将结果归档至 `results/agent_baseline/n8_summary_report.md`。
3. **实验记录与边界**：保留旧 N7 基线和新 N8 全部中间结果、负结果、实际完成样本数、阈值和权重选择依据、候选数量/召回、真实调用记录、API 总支出及必要复现入口。先确认现有任务、缓存及服务器本地未推送修改，两个研究线隔离输出；不得改动正式测试集、未经人工批准的新任务数据或历史评分。
