D

Agent 一张图怎么跑（G1）

  • 输入：第一次请求只有 2 张图和指令。T5.1 的 2 张图叠加了给定掩码的轮廓。
  • 看图：Agent 每调用一次 view，得到一对两期放大图，留在对话历史里。
  • 图数上限：一次请求最多 16 张，即开局 1 对加之后 7 对。再多就只留开局 1 对和最近 3 对。
  • 预算：最多 30 次回复。
  • 验证器固定阶段：每次准备提交时，自动核验掩码里未核验的组件，也核验给定但已删除、没有答案的组件。
  • 谁决定：规划器。程序不自动删除。ask() 不带参数时核验未核验组件，每次最多 64 个。
  • 真值：只有记录器读取，用于事后评分。单元测试检查它不进入 Agent 输入。
