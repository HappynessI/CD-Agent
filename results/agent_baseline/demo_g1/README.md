# G1 回放页

配置 G1：flash 规划器、flash 验证器、固定核验阶段。验证集，离线可打开。先打开 `index.html`，里面有系统流程图和四个回放的入口。每个回放页也带这张流程图，并标出这次运行的工具调用次数。

| 文件 | 内容 |
|---|---|
| `T5.1_val_64_showcase.html` | 第 3 次运行，初始 53.52 → 报告时 45.57 → 最终 91.22 |
| `T1.1xC0_val_27_showcase.html` | 第 1 次运行，报告时 90.20 → 最终 90.95 |
| `T5.1_val_40_failure.html` | 第 1 次运行，初始 65.23 → 最终 51.91 |
| `T1.1xC0_val_57_failure.html` | 第 2 次运行，最终 35.87，第 30 次回复直接提交 |

这些是挑出来的样例，不代表平均水平。`T5.1_val_64` 没有满足 `pick_demo.py` 的「至少三类工具」条件（只用了看和修改）。选它是因为它最清楚地展示报告怎样改变决定。

页面不显示每轮的状态行，完整内容在服务器轨迹的 `messages.jsonl`。

生成方式：`code/agent_baseline/make_demo.py`，入口页用 `--hub`。
