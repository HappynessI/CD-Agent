3 种做法：固定路线、固定规则、Agent

这个页面说明 3 种做法的结构，并在一张图上比较它们的结果。

3 种做法的结构

3 种做法使用同一套工具。固定规则和 Agent 使用同一个验证器。差别只在谁做决定。

  • 固定路线：程序按固定顺序和固定参数调用工具。不用规划器，不用验证器。不同任务的固定路线不同。
  • 固定规则：程序把固定路线的掩码拆成组件，全部组件批量送给验证器，删除答 no 的组件。不用规划器。不补漏。所有任务使用同一个结构。
  • Agent：规划器决定每一步。验证器的答案只作为证据。

选择「固定路线」后，再选择任务。

规划器决定调用哪些工具、问哪些组件、是否采纳答案、何时提交。规划器可以补漏，也可以修改组件。

各任务的对照是什么
