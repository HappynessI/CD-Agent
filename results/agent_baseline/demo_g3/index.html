系统流程（G3）

输入 →

T1、T2、指令；按任务可带给定掩码、region#0、示例、反馈或旧地图。真值仅用于事后评分。

规划器 ↔ 原子工具

每轮选择工具，读取结果、图像和句柄，决定当前答案。没有一键生成变化掩码的工具。

submit → 提交门 → 输出

固定核验阶段拦截首次提交及仍欠核验的组件，返回报告；规划器据此编辑或再次提交。预算报告给出复核机会，耗尽或异常时使用当前答案兜底。

独立验证器 ↔ 规划器

只收组件裁图与任务核验问题；回答 yes/no、类型、理由及可空的 p_yes。看不到规划对话，答案是证据，不自动删组件。
