术语

会话
Agent 处理一张图的全过程。
步
规划器的一次回复，以及这次回复发出的工具调用。
当前掩码
会话中最新的候选结果。
最终掩码
会话结束时提交的掩码。
组件
掩码中的一个 8 连通区域。
给定掩码
T5 任务的输入掩码。这个掩码来自固定路线。
区域 region#0
C2、C4 任务给定的框。答案只能在框内。
示例掩码
T3.1 给定的一处变化。Agent 找同类的变化。
规划器
决定调用哪些工具、保留哪些组件、何时提交的模型。
验证器
判断一个组件是否是真实变化的模型。它独立于规划器。
harness
运行规划器和工具的程序。G1–G4 是它的版本。
提交门 Gate
harness 中的一个结构。规划器调用 submit 时，提交门判断是否暂停提交。
固定路线
程序按固定顺序和固定参数调用工具。不用规划器，不用验证器。
固定规则
在固定路线的组件上运行验证器，删除答 no 的组件。不用规划器。
固定响应
反馈任务（T5.2、T5.3）的固定路线。程序按反馈的位置直接修改给定掩码，不用规划器。
虚线框工具
默认关闭的执行工具，用命令行开关 --tools-t13 打开。T1.2、T1.3、T3 使用。
F1ᶜ
累计全部图的 TP、FP、FN 后计算的 F1。单张图的 F1 写作 F1。
真值
数据集提供的变化标注。真值只用于事后评分。
