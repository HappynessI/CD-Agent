核心工具

Agent 只能通过这些原子工具工作，没有一键输出变化掩码的工具。

工具名与参数直接读取注册 schema；后端及行为说明依据实现。共 23 个工具（含可选开关）。

数据流

输入
T1、T2、指令
可选给定掩码 / 区域 / 示例 / 反馈 / 旧地图
→
规划器调用原子工具
查看、分割、比较、特征、运算、修改、核验
→
句柄与证据
mask#k、inst#k、props#k、feat#k
输入 region#0、map#0
外部 example#k、exmask#k；视图 view#k
→
submit → 提交门
报告 → 规划器复核
通过后输出二值掩码

核验

ask

向独立验证器询问掩码组件是否符合任务变化要求。

regionsarray否未定义
schema 约束

      },

        "type": "array",

          "type": "integer",
          "minimum": 1
        },

      }
    },
    "required": [
      "mask"

    "additionalProperties": false
  }
}

输出：逐组件 answer、type、reason、p_yes、status；剩余未核验数

后端：可配置验证器；CLI 默认 qwen3.7-plus，G3/G4 本批轨迹用 qwen3.7-flash；也支持本地验证器

开关：默认开

任务：T1 / T3 / T4 / T5；实际取决于会话输入与开关，代码未定义逐任务白名单

当前答案：不改变；更新核验账本

  • G4：此工具不直接产生最新 mask 提醒。
  • G3：自动选择仅包含反馈点半径 32 像素/方位格内或被编辑的相关组件；显式 ids 不经过此筛选。每次最多 64 个组件，无法解析不等于 no。
代码中的用途原文
Ask the independent verifier about building change in mask components. With no arguments it checks the components of your current answer that have no answer yet, largest first, up to 64 per call; remaining_unverified says how many are left. For a mask without ids, the same on that mask. With ids it asks about exactly those components, up to 64 in total. Returns answer, type, reason, p_yes (relative yes/no reading, may be null), status. Unparsed is not no.

句柄、核验与提交

工具创建新句柄，保留旧 mask / inst / props / feat 数据。select 和 remove_region 保留未删区域的 ID，其余编辑可重编号。当前答案是单独的指针；set_current=false 保留中间候选，不覆盖当前答案。map#0 与 region#0 是输入，不自动成为当前答案。特征网格只读；外部示例会缓存特征，核验账本与待办清单也会更新，因此“只出新句柄”不等于没有任何状态变化。

map_input.py 与 feedback.py 不注册额外工具。旧地图通过 --map-input 进入 map#0；外部示例通过 --external-examples 扩展 match_exemplar 的 exemplar，并增加可选 negative。反馈点和方位进入指令及 G3 相关组件筛选。完整参数来自 session_schemas，schema 没有单独定义参数含义时写“未定义”。

ask 不接收规划器的对话或理由。后端接收组件的 T1/T2 裁图与任务核验问题；--ask-correspondence 开启时是近景两张与环境两张，关闭时为两张近景。输出 yes/no、type、reason、可空 p_yes 及解析状态；p_yes 未校准。ask 不自动修改掩码。G3 自动核验受反馈相关性约束，显式 ids 仍可指定组件。

提交门需 --verify-stage。首次提交或仍欠核验时返回报告，规划器复核后编辑或再次 submit。G3 大框限制只用于 segment_prompt；区域外像素与方向违反进入报告。G4 在有区域时才对实际提交掩码与 region#0 求交；当前答案提醒仅比较句柄，方向违反仍只报告。异常/预算耗尽仍可兜底，页面选例会排除非 model 提交，除非全部兜底。
