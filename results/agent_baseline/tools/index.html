核心工具

Agent 只能通过下面的原子工具工作。没有一次输出变化掩码的工具。工具名和参数从代码中注册的定义读取。

23工具总数
14默认可用
9要用命令行开关打开

结果编号、验证器和提交门

结果编号

  • 工具只生成带新编号的结果，不修改已有结果。
  • 编号种类：mask#k、inst#k、props#k、feat#k、view#k。
  • 输入编号：给定掩码 mask#0、区域 region#0、旧地图 map#0、外部示例 example#k、exmask#k。
  • 当前掩码是一个单独的指针。set_current=false 时，工具不修改当前掩码。

验证器（ask）

  • 验证器只接收组件的 T1、T2 裁剪图和验证问题。
  • 验证器不接收规划器的理由和对话。
  • 输出：yes 或 no、变化类型、理由、p_yes。p_yes 没有校准。
  • 每次最多验证 64 个组件。答案无法解析时，不等于 no。
  • ask 不修改掩码。规划器决定是否删除组件。

提交门（submit）

  • 第一次 submit 时，提交门暂停提交并返回报告。
  • 再次 submit 时，掩码含未验证组件才暂停。
  • G3：报告列出区域外像素和方向错误。
  • G4：有 region#0 时，提交的掩码与区域求交。
  • 预算用完或会话异常结束时，harness 提交当前掩码。
