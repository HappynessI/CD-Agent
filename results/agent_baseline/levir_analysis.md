# LEVIR-CD 分析：什么在限制 Agent 的 F1

只用验证集 64 对。数据来自 `code/agent_baseline/levir_analysis.py`。理想决策用了真值，只用来算上限，不进入 Agent 的任何输入。

## 结论

1. 单次运行不足以下结论。两次单跑的 T5.1 相差 2.66 分，之后所有比较都用 3 次重复。
2. 工具改进有效。同工具下，plus 第 7 轮的 T5.1 明确高于固定组合 83.15（+2.57 [+1.06, +4.72]）；T1.1 还没有明确超过（+0.60 [−2.12, +2.70]）。flash 规划器都没有明确超过。固定规则 86.35 仍高于所有 Agent 配置；它使用 MLLM，是参照，不是主要比较对象。
3. 理想删除 87.86 不是现实目标。被新核验接受的纯误检里，抽样约一半在人眼看来是真实的新建、拆除或工地，只是真值没有标，零样本系统不应该也无法靠规则去掉（见下节）。
4. 真正可修的核验错误是：同一栋建筑两期外观不同（光照、遮挡、屋顶颜色），模型仍判新建。抽样里约占 44%。
5. 边界有一部分能改，但不是靠换分割模型：SAM ViT-H 框提示和超像素都变差。SAM3 自己的像素门限从 0.5 提到 0.85，固定路线 +1.01，高于腐蚀的 +0.43，说明软输出确实含边界信息。
6. 没有系统性错位：逐图最佳平移的中位位移是 0，上限只高 0.20。

flash 跑完一个候选池约 0.7 元，plus 约 7 元。问法要求先在两期找到同一对象，比较轮廓、屋顶和相邻固定物，两期是同一栋建筑、只有外观不同时答否。问法是看过这批图的错误后设计的，区间只反映图的抽样，不包含这个选择偏差。

每期分问的假设是错的：它想用「两期都有建筑」排除同一栋建筑，但单期判断噪声太大，真变化也常得到两个相同答案。

### 被新核验接受的纯误检是什么

纯度 < 0.1 且 qwen3.7-plus 四图答「是」的组件共 398 个、219,861 像素（全部误检的约四分之一）。按面积加权随机抽 36 个，人工看两期裁块，结果如下。按面积加权抽样，所以个数比例近似面积比例。

| 看到的情况 | 个数 | 比例 |
|---|---:|---:|
| 同一栋建筑两期都在，外观不同（光照、遮挡、屋顶颜色），模型判错 | 16 | 44% |
| 看起来确实是建好的新建或拆除，真值没标 | 13 | 36% |
| 工地、地基、框架（是否算变化取决于标注口径） | 6 | 17% |
| 看不清 | 1 | 3% |

这是我一个人在低分辨率裁块上的目视判断，没有复核，也没有查原始标注，「真值没标」只表示人眼看着像变化，不等于标注错误。工地口径是看真值才知道的，不能写进提示。
