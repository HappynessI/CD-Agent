# 可视化示例（给导师汇报用）

每个 HTML 都是单文件，可以离线打开，内容是：输入 → 每一步的推理和工具调用 → 输出和指标。

**这些是挑出来的样例，不代表平均水平。** 整集指标写在每页页头。真值、F1 只由记录器计算，Agent 运行时看不到。

示例来自验证集。测试集上的正式展示轨迹要等配置冻结后再做（README 第 8 节）。

## 挑选标准（`code/agent_baseline/pick_demo.py` 输出全部 64 张的检查表）

1. 正常 `submit`，不是预算强制提交；
2. 至少用到 3 类工具；
3. 至少一次看图之后的修改，且这一步 ΔF1 > 0；
4. 最终单图 F1 不低于该配置的整集 F1^c；
5. 步数在 8–20 之间。

失败样例的挑法：T1.1 取 F1 接近下四分位且有真实变化的图；T5.1 取修正后变差最多的图。
