## T3-2 frozen design before execution

An endpoint predicted building/playground routes to instance; otherwise dense. Geometry and all E mean probabilities are recorded, but no GT groups/ID are used to route.

Confirm evaluates branch-inst, branch-dense, deterministic route, and the single frozen hybrid, without reselection. Explicit frozen files: step2/instance_frozen.json and step2/system_frozen.json. ## T3-3 frozen design before pool preparation

Use the tune-frozen T3-2 system and feature rank, then reconstruct the actual candidate pool before ranking: structural route uses every cleaned instance, nonstructural route uses every 8-connected routeA component, structural union hybrid combines all clean instances with all high-confidence dense components, structural intersection hybrid transforms each clean instance by high-confidence dense intersection. DINO features and similarities are recomputed on each actual mask; original-mask identity comparison records how many masks are new. All masks already exclude E.

Relative margin uses all candidate scores except the highest: z=(s1-mean(background))/(population std(background)+1e-6). For N=0/1 define z=0; N=0 always yields empty.
