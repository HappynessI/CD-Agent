## T3-2 frozen design before execution

Select one clean instance rank/K on tune only from delta/joint × Top1/3/5/8, maximizing all-task pooled F1; ties smaller K then delta. On all tasks recompute E-dominant class pair directly from the seven predicted channels, and rebuild routeA dense mask from per-pixel argmax class transition, with E excluded. An endpoint predicted building/playground routes to instance; otherwise dense. Geometry and all E mean probabilities are recorded, but no GT groups/ID are used to route.

Structural hybrid variants use intersection or union of selected instance prediction and high-confidence dense support. High-confidence support requires each endpoint's example-predicted class probability >=.7 or >=.85 and membership in the routeA mask. These four variants are computed on tune; freeze the best hybrid and the best route-versus-hybrid system by tune pooled F1 (tie declared route-first order). Confirm evaluates branch-inst, branch-dense, deterministic route, and the single frozen hybrid, without reselection. Explicit frozen files: step2/instance_frozen.json and step2/system_frozen.json. Input arrays, E means, predicted pair and masks are written before offline GT scoring. No API or oracle is used in this stage.

Reproduction: `bash tools/run_n8_t3_route.sh tune`, then `... confirm`, via main-Agent Slurm scheduling (CPU1/12GB/1h). A synthetic routing/fusion test checks that predicted endpoint channels control the branch, not labels.

## T3-3 frozen design before pool preparation

Use the tune-frozen T3-2 system and feature rank, then reconstruct the actual candidate pool before ranking: structural route uses every cleaned instance, nonstructural route uses every 8-connected routeA component, structural union hybrid combines all clean instances with all high-confidence dense components, structural intersection hybrid transforms each clean instance by high-confidence dense intersection. Remove only empty/exact duplicate masks; no dense-component area pruning. This is a new pool/retrieval system, not reuse of old candidate tables. DINO features and similarities are recomputed on each actual mask; original-mask identity comparison records how many masks are new. All masks already exclude E.

Relative margin uses all candidate scores except the highest: z=(s1-mean(background))/(population std(background)+1e-6). For N=0/1 define z=0; N=0 always yields empty. Directed semantic consistency is ptrans(C)=mean_x∈C[P_T1(c1,x)*P_T2(c2,x)], with c1/c2 predicted from E foreground probability means. No GT category is used.

On tune only scan z thresholds {0,1,2,3} and ptrans thresholds {0,.1,.25,.5}; accept the task only if both first-candidate evidence values meet threshold and pool is nonempty. Select by pooled all-task F1 of unverified Top5, ties lower z then p. Save step3/gate_frozen.json before confirmation. Then obtain real evidence-card qwen3.7-flash answers for accepted tune Top5, and select K∈{1,3,5} by tune verified pooled F1 (tie smaller K); freeze final K before confirm. Retain an unverified arm with the exact same gate/K, and all three tune K variants, to separate verifier loss/gain. No N7 answer is reused for changed evidence-card input. Confirmation uses only the frozen final system/gate/K.

The evidence prompt contains exactly two quantitative lines: E area and predicted dominant T1→T2 class probabilities; C native area, selected exemplar similarity, C predicted dominant T1→T2 probabilities and example-directed ptrans. Views are original direct4 example/candidate T1/T2 crops. All categories/probabilities originate from predictions, never task IDs, GT or GT-text oracle.
