# N8 实验汇总

依据 `doc/agent_baseline/N8_EXECUTION_SPEC.md`，已按 T3-1→3、FM-1→3 完成候选池重构、开发集标定、冻结确认及真实 qwen3.7-flash 核验。保留原始 N7、GT 和历史预测；本轮未使用正式测试集。离线实验与 T3 三 seed 共60条真实在线会话均已完成；最终统计已完成，全部原始结果与复现材料随报告归档。

## 1. 方法与数据边界

T3 使用 SECOND dev60 原 tune30/confirm30；FM 使用原30记录 tune15/confirm15。推理仅使用任务方向、双期影像、示例 E、初始掩码及模型概率/特征。GT 仅用于开发标定、评分与事后诊断。没有按数据集名称切换推理策略。

| 步骤 | 实际执行 |
|---|---|
| T3-1 | 完整几何候选池按覆盖比或 IoU≥0.15 剔除自匹配，净掩码重新提特征，delta/joint 各 Top1/3/5/8 |
| T3-2 | 示例内模型预测建筑/运动场端点走实例，否则走稠密转换；比较高置信交/并融合，tune 冻结 joint K5 与 route |
| T3-3 | 重构实例/稠密池，图内相对 z 与转换概率门控，tune 冻结 z≥2、p≥0.1、核验 K3；63 次全新证据卡片 API 请求 |
| FM-1 | 拆除仅 S1/S2/S5，其余五源；半径3欧氏圆盘膨胀扣除、连通域≥25、方向语义差阈值 tune 冻结0.2 |
| FM-2 | 门控候选中 DINO 差≥0.2 的残差面积/块数；tune 冻结面积1024触发核验，候选生成仍为100% |
| FM-3 | 语义差×DINO差×面积^alpha，tune 冻结 alpha=0；真实比较 V0/数值证据 × K5/10，398 次全新请求 |

不存在用历史核验答案替代新候选核验；199 对 FM 请求图片、seed、参数全部相同，仅证据文本变化。全部离线请求均有 usage，未报告 API 失败。

## 2. T3 确认结果

F1 均为百分数；非空19任务，空目标11任务。完整逐配置指标见 [T3研究报告](n8_t3_20261115/research_review.md) 与 [最终离线审计](n8_t3_20261115/final_audit.md)。

|---|---:|---:|---:|---:|---:|
| 原 R1 delta Top8 |16.0437|22.4120|12.5135|133931|0/11|
| 去自匹配 delta Top8 |19.7392|22.1205|14.9059|141680|0/11|

最终主方案虽减少空目标 FP 82.24%，但12/19非空任务输出全空，正目标召回损失显著：非空 P/R=27.3498/6.4635，TP=13074、FP=34729、FN=189200。确认池可覆盖 TP 从完整重构池54599→Top5 31914→Top3 21689→门控13085→核验13074。确认剩余GT共202274像素，重构全池像素覆盖约26.99%，Top5覆盖15.78%，最终召回6.46%。问题主要发生在路由、截断与门控，不能把拒识率提高当作成功。完整池4895→自匹配清理4809；第三步两组重构池共3117候选，其中253为新掩码。

预先固定的重构池 ungated/unverified Top5 对照在 tune/confirm 均达到数值晋级条件：confirm 非空 F1=18.21835，空 FP=58094，较原基线下降56.62%。因此对这一固定对照开展10任务×2组×3seed真实 Agent 验证；主门控方案的失败结论不变。推进决定发生在看到确认结果之后，且在线10例含7个confirm、3个tune任务，因此仅是探索性开发验证，不能声称独立泛化收益。运行入口只返回候选句柄，Agent 自主查看、选择、编辑与提交，不回放离线答案。

[T3十例可视化](n8_t3_20261115/diagnostics10/index.html)：包括微小目标、自匹配收益/损失、示例语义路由错误及空集误报。1496 的模型示例语义预测导致错误结构路由，最终0TP/29049FP；1884 的大块稠密候选被核验接受，空目标FP23778。以上诊断不修改任务GT。

## 6. 结论与后续研究建议

1. N8六个指定步骤均已真实实现与运行；重构候选和新增API核验没有省略。主T3门控组合及FM联合方法都未验证出所要求的可靠净收益，负结果完整保留。
2. T3固定Top5对照达到指定离线数值条件后完成了60条真实Agent验证，但观察到种子波动、目标类退化和空集失守。建议先统一同转移任务与核验语义，再分开检验固定候选使用与Agent自主扩大搜索；本轮不追加改配置实验。
3. FM应优先处理来源裁剪的召回损失、候选局部区域与VLM叙述不一致。数值证据版与增大K都未超过不补漏，不能只继续扫阈值。
4. 10例T3与10例FM诊断、原始请求/响应、全部60条Agent轨迹和冻结参数均保留。本轮全部推理与最终统计已结束；保留原离线归档，并以 `reproducibility_final/` 单独保存在线完成后的源码及执行记录。
