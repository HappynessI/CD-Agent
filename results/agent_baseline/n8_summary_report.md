最终主方案虽减少空目标 FP 82.24%，但12/19非空任务输出全空，正目标召回损失显著：非空 P/R=27.3498/6.4635，TP=13074、FP=34729、FN=189200。确认池可覆盖 TP 从完整重构池54599→Top5 31914→Top3 21689→门控13085→核验13074。问题主要发生在路由、截断与门控，不能把拒识率提高当作成功。完整池4895→自匹配清理4809；第三步两组重构池共3117候选，其中253为新掩码。

预先固定的重构池 ungated/unverified Top5 对照在 tune/confirm 均达到数值晋级条件：confirm 非空 F1=18.21835，空 FP=58094，较原基线下降56.62%。因此对这一固定对照开展10任务×2组×3seed真实 Agent 验证；主门控方案的失败结论不变。推进决定发生在看到确认结果之后，且在线10例含7个confirm、3个tune任务，因此仅是探索性开发验证，不能声称独立泛化收益。运行入口只返回候选句柄，Agent 自主查看、选择、编辑与提交，不回放离线答案。

[T3十例可视化](n8_t3_20261115/diagnostics10/index.html)：包括微小目标、自匹配收益/损失、示例语义路由错误及空集误报。1496 的模型示例语义预测导致错误结构路由，最终0TP/29049FP；1884 的大块稠密候选被核验接受，空目标FP23778。以上诊断不修改任务GT。
