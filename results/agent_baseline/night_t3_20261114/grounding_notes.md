# N2 Grounding对照

固定原dev60与图像级30/30调参/确认划分。B0复用；B1为单时相支持区保真、其余及孔洞压暗70%；B2额外看两期原始裁图，因此不能将差异仅归因显示。标签一致只作诊断，视觉复核与自动标签吻合分开；本轮复核由主Agent执行，不是独立人工真值。完整/正目标/空目标分层见audit.json；原完整评分未改变。

匿名审查图由night_grounding_review_contact仅从已归档输入拼接，不读取预测、GT标签或映射key；审查首先记录可见地物及支持区域，再读取预测核对指代。显示原RGB是审查辅助，不代表B1曾看到这些额外输入。


研究动机来源（原始论文，非本项目效果证据）：[SoM](https://arxiv.org/abs/2310.11441v2)通过分割区域上的标记建立可指称区域，其GPT-4V结果不能直接外推qwen3.7-flash或遥感影像。[细粒度外部知识视觉提示](https://arxiv.org/abs/2407.04681v1)把空间信息嵌入模型级视觉表示；本轮RGB加二值支持面板只借鉴明确空间支持的动机，**不是**该论文模型级注入方法的复现。当前闭源API只收到归档图像/文本，未修改其内部视觉编码器。B1–B3负结果按本项目实测保留。
