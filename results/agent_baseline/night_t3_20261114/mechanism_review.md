# T3 新机制综合复核

本次更新已核对完整JSON：positive-endpoints、SegEarth dense及B2掩码互补诊断的 tune/confirm 均已完成，各split30/30。SegEarth两个历史对照在确认也30/30复现。**SAM文本与dense确认结果不同，不能相互外推。**本页不更改任何评分、标签或配置。所有结果都是离线工具路线；**未执行真实在线 Agent 三 seed 对比**。

固定 tune 含正GT11例、空GT19例；confirm 含正GT19例、空GT11例。两组正GT像素总量分别40315和202274，组间基线难度与样本构成不同。原dev60和确认图像已多轮曝光，本轮确认只能称探索确认，不是未见holdout。下列F1为百分数，计数均扣除示例。

## 1. 解析不能用整体吻合率一概判负

B0/B1/B2/B3 在 tune 正例上的 pair 标签吻合为1/2/4/2（分母11），剩余GT≥16诊断为0/0/2/1（分母8），空例为7/2/2/4（分母19）。所以早先“B3整体6/30低于B0 8/30”的理由不足以说明正例解析变差；B2/B3确有局部标签吻合改善。

这仍不等于支持区定位正确，也不等于检索有效。B2额外看见双期上下文，是表示、说明和时相信息共同改变；B3只在单期增加支持面板。不能将两者差异归因于单一视觉因素。详见 [语义分层审计](semantic_strata_tune/report.md)。

## 2. SAM 文本：负端点排除确实损伤一个实例，但改善未推广

同一预测类别对和同一组SAM缓存，strict与positive-only仅相差两项负端点排除，属于可识别的工具规则对照。

| 阶段/方法 | 正例F1 | 正例TP | 正例FP | 空例FP |
|---|---:|---:|---:|---:|
| tune B2 strict | 0.0198 | 4 | 92 | 6093 |
| tune B2 positive-only | 13.2776 | 3479 | 8610 | 6093 |
| tune B3 strict | 0.0198 | 4 | 5 | 3750 |
| tune B3 positive-only | 13.2997 | 3479 | 8523 | 3750 |
| confirm B2 strict / positive-only | 0 | 0 | 5798 | 3510 |
| confirm B0 strict / positive-only | 11.1986 | 12356 | 6040 | 109 |

表为全候选并集；tune中全并集与固定delta Top8相同。confirm B0 Top8的TP为9104、正F1为8.375，不能将全并集数值当Top8。

B2/B3 tune 新增3475个TP全部来自预先定位的train1808：移除负端点排除确实恢复了被删的交集，但也增加8518个FP。这证明该实例的过度排除，不证明稳定的整体改进。tune B2目标类6个正例仍TP0，恢复全部落在地表类5例中的一例；B2 confirm两规则的评分相同且TP0，说明这次规则放松未带来可推广收益。B0跨阶段表现不同也提示解析类别选择会改变可用提议，不能把B2失败归因于SAM单一因素。

[调参完整结果](positive_endpoints_tune/report.md)；[探索确认完整结果](positive_endpoints_confirm/report.md)。B0 strict与历史结果复现通过；没有使用GT类别补模型查询。

## 5. 固定掩码互补诊断：调参交集不应推广

互补区域在GT评分前固定为SAM-only、dense-only、交集与并集，原始掩码计数均复现。它们是描述性诊断，不是逐例用GT选择工具或部署规则。

| 正例区域 | tune11 TP / FP | confirm19 TP / FP |
|---|---|---|
| SAM-only | 2860 / 8485 | 0 / 0 |
| dense-only | 3190 / 14837 | 9356 / 107602 |
| 交集 | 619 / 125 | 0 / 5798 |
| 并集 | 6669 / 23447 | 9356 / 113400 |

调参交集的619TP全来自train1808，其中FP117；另有8FP来自目标类。正例交集看似误报少，但召回仅覆盖40315GT像素中的619；加上空19例，交集还包含2022FP。因此不能将“619TP/125FP”作为全30例精度表现。

确认交集为0TP，正例FP5798全部位于train1496。**确认正例上的全部SAM FP5798都已包含在dense中**；这不是所有确认SAM误报都包含的断言：空例还有931个SAM-only FP，其中1129为358、1527为532，其余41。全30确认交集FP8377（正例5798、空例2579）。

确认并集没有增加一个TP，正例与dense相同（9356TP/113400FP），空例却从dense的67323增至68254（+931）。tune并集的正例F1 18.9377不能据此推广；确认不支持两工具的简单互补收益。交集会删除dense的全部真阳性，也不应推广。目标类确认TP全在dense-only，地表类交集只有误报，说明“两个工具同意”并非可靠正确性信号。[调参互补](b2_mask_complementarity/tune/report.md)；[确认互补](b2_mask_complementarity/confirm/report.md)。

## 6. 机制结论与后续建议

现在有证据区分三种问题：解析标签吻合有局部改善，但不等于支持区定位可信；同一解析接不同分割工具会改变覆盖；放松SAM负端点排除可救回特定实例，却没有建立跨图稳定性。dense改善部分误报计数，但其确认召回集中于一张目标类图，地表类几乎无有效覆盖。简单交集和并集的调参迹象在确认上不成立。

**下一步应优先研究与类别预测独立的变化证据及其空间定位，而不是继续挑选union/intersection或扫语义阈值。** 可先针对已固定失败类型审查：2438为何有变化覆盖而其余目标正例没有；1496为何两工具在非GT区域共同响应；2075等空例的大面积dense响应对应什么影像证据。这些是机制问题，当前计数不能证明由邻域、混合支持、配准或标签歧义中的哪一种导致。下一轮若提出新方法，应预声明独立的变化证据来源、固定新的开发设计及正/空目标，而不是在已曝光确认例上选规则。本页不启动任何新实验。

本夜mean-endpoint同池组合、patch集合排序、direct4与残余核验等负结果继续保留：它们否定相应固定实现的改进，不构成“示例检索无效”或“所有语义解析变差”的普遍结论。当前不支持在线晋级；本夜没有真实在线 Agent 三 seed 结果。
