任务定义见 `doc/change_dection_agent.md`。代码在 `probe/objects.py`、`probe/exp1_error_breakdown.py`，逐目标记录与汇总在 `exp1/<数据集>/<检测器>/`。

## 设置

- 数据：LEVIR-CD test，128 张 1024×1024；WHU-CD test，690 张 512×512（官方整图 test 区，与 SChanger 的 WHU-CD256-HANet 测试区相同）。
- 检测器：SChanger-small 和 SChanger-base 使用官方 LEVIR/WHU 权重，按官方协议做 256 无重叠切块推理，阈值 0.5。复现的像素 F1 与官方表一致：LEVIR 92.44 / 92.88，WHU 93.51 / 93.20。SAM3+OmniOVCD 是旧原型的零样本初态：SAM3 对每期以 "building" 文本提示分割（256 切块后拼回），再做 OmniOVCD overlap-presence 匹配（阈值 0.25），**只有二值输出，不参与阈值扫描**。
- 判定标准与任务说明一致，没有修改：真值和预测各取 8 连通域；最佳 IoU ≥ 0.5 为命中，0.1–0.5 为部分命中，< 0.1 为整目标漏检；与所有真值 IoU < 0.1 的预测目标为整目标误检。误差像素按所属目标归类：FN 像素按其真值目标，FP 像素按其预测目标（≥ 0.5 记边界，0.1–0.5 记部分命中，< 0.1 记整目标误检）。因此“边界误差”就是命中目标内部的 FP + FN，四类像素之和等于全部 FP + FN。
- 补充统计两项，用于解释部分命中和漏检：部分命中中真值像素被预测覆盖 ≥ 50% 的比例，以及漏检目标中与预测零接触的比例。

## 结论

1. **两个数据集的误差结构不同。** LEVIR 上 SChanger 约 73–74% 的误差像素是命中目标的边界误差，整目标漏检只占 8.7–8.8%，即 222–230 个真值目标（3.2%）。WHU 上边界误差降到 47–50%，整目标漏检占 19–23% 的误差像素，即 150–181 个目标（15–18%）。
2. **LEVIR 的“部分命中”多数是粘连，而不是漏检。** 85–88% 的部分命中目标已有一半以上像素被预测覆盖；IoU 低的原因是相邻房屋和中间空地被预测成一个连通块（例如 `partial_0.png`）。这类误差实质上属于边界/实例分离问题。WHU 上只有 41–46% 的部分命中被覆盖过半，更接近真正的部分漏检。
3. **漏检集中在小目标，而且检测器对它们几乎没有响应。** < 100 像素目标的漏检率为 48–57%（LEVIR）和 81–87%（WHU）；WHU 100–1000 像素目标的漏检率仍有 35–41%。82–91% 的漏检目标与预测完全没有接触。
4. **降阈值几乎补不回漏检。** 阈值降到 0.05 时，SChanger-base 只找回 26/222（LEVIR）和 33/150（WHU）个整目标漏检，其中成为命中的只有 3 和 7 个；同时整目标误检从 500 增加到 789、398 增加到 981，F1 单调下降。漏检目标的检测器概率接近 0，概率图本身不含召回信号。阈值很低时，部分命中目标也会和邻居粘连成更大的块，因此整目标漏检数在 LEVIR 上反而略有上升（222→268）。
5. **零样本 SAM3+OmniOVCD 不能直接作为强检测器的替代。** 它的 F1 只有 73.1（LEVIR）和 56.4（WHU）；WHU 上 61% 的误差是整目标误检（4441 个预测目标中有 3698 个与真值无关），这一基线的变化图只由“仅在一期被分割出来”的建筑实例构成，因此这些误检都是 SAM3 两期分割不一致造成的（同一栋未变化建筑在一期漏分或在一期误分）。

对后续方向的含义：在 LEVIR 上，强检测器剩余的误差主要在边界和粘连，召回侧可改进的总量很小；在 WHU 上，整目标漏检占比明显更高，召回侧有实际空间。两处漏检的共同特点是检测器没有任何信号，补漏检不能依赖检测器概率图，需要独立的候选来源（例如 SAM3 建筑实例或网格扫描）。

## SYSU-CD 与 SECOND（2026-10-16 追加）

为了看到 LEVIR/WHU 之外的问题，用户要求加入两个通用变化数据集，用全部 test 集：SYSU-CD 4000 张 256²，只有二值变化标签，变化类型包括建筑、道路、植被、填海等；SECOND 1694 张 512²，两期各有 6 类地物标签。检测器为 SChanger-small/base 的官方 SYSU 权重（复现 F1 84.58 / 84.17，与官方一致）和 MambaSCD-Base（SECOND，官方权重，F1 74.17）。SAM3 零样本基线只针对建筑，这两个数据集不使用。

**判定的两处调整（原因见下）**

1. **SECOND 的真值目标按变化类型拆分**：先按（t1 类别，t2 类别）分组，再取 8 连通域。否则相邻的不同变化（如“植被→地表”紧接“地表→建筑”）会连成一个混合目标，无法按变化类型统计。代价是产生大量类别交界处的碎片：47.5% 的目标小于 20 px，但只占变化像素的 0.1%。所以目标级统计同时看全部目标和 ≥ 20 px 的目标（`gt_object_counts_area_ge20`），像素级统计不受影响。
2. **补充“无信号漏检”（预测覆盖目标像素 < 10%）**：SECOND 上，大量小目标被一个大预测块覆盖，覆盖率很高但 IoU < 0.1。按原定义，它们是“整目标漏检”（37–44% 已被覆盖过半）。原定义照常报告，新口径作为补充列，对四个数据集都计算。LEVIR/WHU 上两种口径基本一致，因为它们的漏检中 82–91% 与预测零接触。

**结论**

1. **两个通用变化数据集的误差结构都不再以边界为主。**
   - SYSU：边界 43–45%，部分命中 27%，整目标漏检 15–19%，误检 11–13%。
   - SECOND：整目标漏检 36%，部分命中 31%，误检 18%，边界只有 15%。
   - 对比：LEVIR 边界 74%，WHU 47–50%。
2. **SECOND 上，难漏的是“语义变化”，而不是小目标。**
   - 新建建筑几乎不漏：地表或低矮植被 → 建筑，无信号漏检像素只有 1.8–5.4%。
   - 改建（建筑 → 建筑）达 40%；植被相关变化（树 ↔ 低矮植被、低矮植被 → 树等）为 25–43%；地表 ↔ 植被为 21–26%。
   - 这类变化里检测器常常完全没有响应。整体上，无信号漏检占真值像素的比例：SECOND 14.9%，SYSU 4.3–5.4%，WHU 2.5–2.8%，LEVIR 1.2–1.3%。
3. **SYSU 的漏检集中在小、中目标**：< 100 px 的目标几乎全漏（93–98%），100–1000 px 漏 55–59%，> 1000 px 只漏 13–15%。但 > 1000 px 的目标占 SYSU 变化像素的 99%，所以无信号漏检只占像素的 4–5%。
4. **这两个数据集上阈值没有校准好，降阈值有少量收益，与 LEVIR/WHU 不同。**
   - SYSU：降到 0.2–0.4 时 F1 +0.1 到 +0.3。降到 0.05 可找回 386–532 个漏检目标（28–41%），但多数只成为部分命中，整目标误检增加 58–109%。
   - SECOND：降到 0.4 时 F1 +0.3，再往下就快速下降。
   - 可见对通用变化，检测器概率里还有一部分召回信号，但不足以解决问题。
5. **误检明显更多。** SECOND 上 26299 个预测目标中有 15743 个是整目标误检，SYSU 上为 40–43%。召回侧补漏检的同时，确认环节需要更强的区分能力。
