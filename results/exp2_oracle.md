# 实验 2：SAM3 oracle 上界

代码在 `probe/exp2_prepare.py`（真值提示）、`probe/exp2_sam3_oracle.py`（SAM3 推理）、`probe/exp2_compose.py`（替换与计分）；产物在 `exp2/<数据集>/`：`prompts.jsonl`、`sam3/*.npz`、`metrics.json`、`objects.jsonl`。

## 设置

- SAM3：`models/sam3/sam3.pt`，使用 SAM1 任务的交互头（`predict_inst`，单掩码输出，与官方框提示示例一致）。每个真值目标只跑一次，结果供三个检测器共用。
- 提示：真值目标外接框；或外接框加 1 个正点（目标内部离边界最远的像素）。
- 裁块：所有目标都先裁块再送 SAM3，裁块为以目标为中心的正方形，边长 = max(3 × 外接框长边, 128 px)，超出影像时截到影像范围。SAM3 内部再缩放到 1008。
- 时相：WHU 有两期建筑标签，918 个目标判为新建（喂 t2），52 个为拆除（喂 t1），45 个无法判定（两期都跑）。LEVIR 没有分期标签，7027 个目标都两期跑，取与真值 IoU 高的一期，最终 96% 选了 t2。各期 IoU 都记录在 `objects.jsonl` 的 `view_iou`。
- 设定（阈值 0.5 的检测器输出为起点）：
  - **2a 精度侧**：每个命中目标删去与之匹配的预测连通域，贴上 SAM3 掩码。
  - **2b 召回侧**：每个整目标漏检直接并入 SAM3 掩码。
  - **both**：2a + 2b。
  - 补充：**2a_select** 只在 SAM3 的 IoU 高于检测器时才替换，相当于 agent 带有一个完美的接受/拒绝判断；**both_select** = 2a_select + 2b；**2c** 把部分命中目标的 SAM3 掩码并入（只并不删，因为它们的预测连通域常与邻居共用）。
- **对判定的一处修改**：第一版 2a 直接删除整个匹配连通域（表中 `2a_strict`）。诊断发现，在 WHU 上这些连通域经常同时覆盖相邻的另一个真值目标，整块删除会误删 11.8 万个本来正确的像素（例如 `test_255` 一张就损失 4.9 万 TP）。这部分损失不属于“SAM3 边界是否更好”，所以正式的 2a 删除连通域时保留其落在其他真值目标上的像素。两种口径都列在表中。

## 结论

1. **精度侧：即使提示完美，SAM3 也不比强检测器的边界好。** 对 SChanger 已命中的目标，SAM3 只在 30–41% 的目标上 IoU 更高。全部替换后 LEVIR 的 F1 下降 1.2–1.5，WHU 基本不变（−0.1 到 −0.3）。LEVIR 上 SAM3 平均 IoU 0.867，低于 SChanger 的 0.878–0.883：SAM3 给出的单体建筑轮廓与 LEVIR 的标注口径存在系统差异，检测器则是在该口径上训练的。即使给 agent 一个完美的“何时替换”判断（2a_select），上界也只有 +0.50–0.56（LEVIR）和 +0.79–0.93（WHU）。
2. **召回侧：有界、偏小，但完全为正。** 漏检目标用真值框提示后，SAM3 的平均 IoU 为 0.81–0.84，95–98% 的 IoU ≥ 0.5。补齐全部整目标漏检后，F1 提升 +0.50–0.55（LEVIR）和 +1.18–1.32（WHU）。再把部分命中的目标并入（2c）在 WHU 上还有 +0.9–1.0，在 LEVIR 上无收益。
3. **两侧都选对时的总上界（both_select）**：LEVIR 93.88 / 93.55（+1.0 / +1.1），WHU 95.15 / 95.74（+1.95 / +2.23）。召回侧在 WHU 上贡献更大，在 LEVIR 上与精度侧相当。
4. 对零样本 SAM3+OmniOVCD 基线，两侧上界都大得多（LEVIR 73.1 → 85.0，WHU 56.4 → 68.8），主要来自 2b。基线弱时，“补漏检”的上界是主要部分。
5. 框 + 1 个正点和纯框几乎没有区别（F1 差 ≤ 0.17），点提示对这一上界不重要。

这些数字只是**提示完美**时的上界：漏检目标的位置和外接框直接取自真值，LEVIR 的时相选择也用了真值 IoU。实际 agent 需要自己找到漏检位置并判断时相，所以召回侧能拿到的只会是上表的一部分。

**结论**

1. **通用变化上，SAM3 的分割质量明显下降。** 真值框提示下，全部目标的平均 IoU：LEVIR 0.86，WHU 0.91，SYSU 0.78，SECOND 0.71（SECOND < 100 px 的目标仅 0.65）。SAM3 擅长“物体”，成片的地表、植被、水体变化边界含糊，它的掩码不一定与标注一致。
2. **精度侧依然不值得作为主线。**
   - SYSU：全部替换降 3.5（加正点后降 1.6），即使有完美判断器也只有 +1.6。
   - SECOND：MambaSCD 的边界较差，SAM3 在 84% 的命中目标上更好，所以直接替换也有 +1.1，有完美判断器也只有 +1.5。
3. **召回侧在通用变化上空间大得多。**
   - 补齐整目标漏检：SYSU +1.9 到 +2.5，**SECOND +7.8**。LEVIR 只有 +0.5，WHU +1.2。
   - SECOND 上再补部分命中目标（2c）还有 +3.0，SYSU 为 +1.4 到 +1.8。
   - 漏检目标在真值框提示下的 SAM3 IoU：SYSU 0.78（97–98% 的 IoU ≥ 0.5），SECOND 0.68（85% ≥ 0.5）。工具质量下降了，但仍可用。
4. **两侧都做对的总上界**：SYSU +3.5 到 +4.0，SECOND +9.1，远大于 LEVIR（+1.0）和 WHU（+2.0）。改进空间集中在**通用变化**和**召回侧**。
5. 和上文一样，这些都是提示完美时的上界。SECOND 上召回侧的难点在于：大量漏检属于改建和植被等语义变化，检测器没有信号（见实验 1）。agent 能否自己找到这些位置，是实际收益的关键。
