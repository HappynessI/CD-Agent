# 摸底实验总结（2026-10-16）

任务：`doc/change_dection_agent.md`。数据为 LEVIR-CD test（128 张 1024²）和 WHU-CD test（690 张 512²）。检测器为官方权重的 SChanger-small/base（复现 F1 与论文一致）和旧原型的零样本 SAM3+OmniOVCD。下文数字默认取 SChanger-base，括号内为 small。详细结果：`exp1_error_breakdown.md`、`exp2_oracle.md`、`exp3_mllm_verify.md`；环境：`env.md`。

## 1. 哪类误差占大头

| | LEVIR | WHU |
|---|---:|---:|
| F1 | 92.88（92.44） | 93.20（93.51） |
| 边界误差占误差像素 | **74%**（73%） | **47%**（50%） |
| 整目标漏检占误差像素 | 9%（9%） | **19%**（23%） |
| 部分命中 / 整目标误检 | 11% / 6% | 17% / 17% |
| 整目标漏检目标数 | 222 / 7027（3.2%） | 150 / 1015（15%） |
| < 100 px 目标漏检率 | 48%（57%） | 81%（87%） |

- **LEVIR 以边界误差为主。** 部分命中中 85% 已被覆盖过半，主要是相邻房屋粘连成一块，本质上也是边界/实例分离问题。
- **WHU 的整目标漏检占比明显更高**，100–1000 px 目标的漏检率也有 35%（41%）。
- 漏检目标的检测器概率接近 0，82–91% 与预测零接触。阈值降到 0.05 只能找回 9–22% 的漏检，而且多数只到部分命中，整目标误检却增加 54–146%，F1 单调下降。**概率图里没有召回信号。**

## 2. 精度侧和召回侧的上界（SAM3 + 真值框提示，F1 变化）

| | LEVIR | WHU |
|---|---:|---:|
| 2a 精度侧：命中目标全部换成 SAM3 | **−1.49**（−1.24） | −0.10（−0.28） |
| 2a_select：只在 SAM3 更好时替换（完美验证者） | +0.50（+0.56） | +0.79（+0.93） |
| 2b 召回侧：补齐整目标漏检 | **+0.50**（+0.55） | **+1.18**（+1.32） |
| 2a + 2b | −0.98（−0.67） | +1.06（+1.03） |
| 2a_select + 2b（两侧都做对的总上界） | +1.00（+1.11） | +1.95（+2.23） |

- **精度侧：直接用 SAM3 换边界有害。** 只有 30–41% 的命中目标 SAM3 更好；即使加上完美的接受/拒绝判断，上界也只有 +0.5 到 +0.9。
- **召回侧：上界不大，但无需验证就全部为正。** LEVIR 为 +0.5，WHU 为 +1.2 到 +1.3；WHU 上再补部分命中还有 +0.9 到 +1.0。漏检目标在真值框提示下的 SAM3 IoU 平均为 0.81–0.84，95–98% 的 IoU ≥ 0.5，**分割工具本身不是召回侧的瓶颈**。
- 这些都是提示完美时的上界，实际 agent 还要自己找出漏检位置。
- 对零样本 SAM3 基线，召回侧上界很大（LEVIR +9.7，WHU +10.3），但它与强检测器差距太大，不适合作为 agent 的起点。

## 3. MLLM 能否胜任验证（零样本）

| AUC | LEVIR：Qwen3.5-4B / qwen3.7-plus / 检测器 | WHU：Qwen3.5-4B / qwen3.7-plus / 检测器 |
|---|---:|---:|
| 检测器已预测的区域：命中 vs 误检 | 0.74 / 0.82 / **0.94** | 0.79 / 0.85 / **0.98** |
| 降阈值新区域（正样本仅 21 / 43） | 0.57 / 0.67 / 0.43 | 0.70 / 0.71 / 0.45 |
| 补充：漏检目标 vs 未变化建筑 | 0.79 / **0.89** / 0.92 | 0.89 / **0.93** / 0.93 |

- **两种模型都不能作为检测器输出的过滤器。** 对误检回答“是”的比例，4B 为 74–76%，qwen3.7-plus 为 91–92%。更强的模型排序更好，但仍明显不如检测器自身的置信度。
- **召回侧有实际能力。** 判断一栋建筑是否在两期间出现或消失时，qwen3.7-plus 在 WHU 上 AUC 0.93、准确率 86.5%（漏检判“是”91%，未变化建筑判“是”18%），与检测器低概率的排序能力持平，两者可能互补；在 LEVIR 上为 0.89 / 76%。
- 主要错误：偏向回答“是”，把停车场、植被、堆放物、车辆等非建筑变化或外观差异当成建筑变化。另有部分“错误”实为真值遗漏。
- GPT（gpt-6.1-sol）已获授权，但运行时本地转发通道断开，没有结果。

## 4. 对主攻方向的判断

1. **召回侧值得做，WHU 型数据（漏检占比高）上更值得做；精度侧不值得把 SAM3 + 验证器作为主线**：其上界与召回侧相当或更小，而且需要一个比检测器更可靠的验证者，实验 3 显示目前没有。
2. 召回 agent 的关键模块是**候选生成**，而不是分割工具或阈值。检测器对漏检没有信号，SAM3 在给出位置后分割质量足够。候选需要独立来源，例如 SAM3 双期建筑实例差异或网格扫描，再加上**建筑语义明确的变化确认**；检测器的低概率仍有排序价值，可以作为辅助特征。
3. 如果按“不能放过漏检”的要求只做召回侧，在 SChanger 这类强检测器上，补齐整目标漏检的上界约为 LEVIR +0.5、WHU +1.2 到 +1.3 F1；WHU 上补部分命中另有 +0.9 到 +1.0（两者没有联合计算）。这是上界，实际收益取决于候选的召回率和确认的准确率。
