# 实验 4a：召回候选来源的覆盖率

任务：仓库 `doc/exp4_recall_candidates.md`。代码：`probe/exp4_sam3_extract.py`（SAM3 语义、建筑实例、编码器特征、样例检索）、`probe/exp4_candidates.py`（候选生成与覆盖统计）、`probe/exp4a_analyze.py`（汇总与可视化）。中间结果在 `exp4/<数据集>/`。

## 口径

- **检测器**：SECOND 用 MambaSCD-Base，SYSU 用 SChanger-small，阈值 0.5。
- **目标集合 M**：无信号漏检，即检测器覆盖目标像素 < 10%、面积 ≥ 20 px 的真值目标。SECOND 的真值目标按（t1 类别，t2 类别）拆分。目标数：SECOND 14885 个，SYSU 1059 个。
- **M_partial**：部分命中目标中检测器没覆盖的像素，按像素统计，作为次要指标。
- **候选的筛选**：去掉被检测器 0.5 预测覆盖超过 50% 的候选；面积 < 10 px 的候选也去掉。后一条是新加的，否则噪声碎片太多，而面积 < 10 px 的候选本来就覆盖不了 ≥ 20 px 目标的一半。
- **覆盖的定义**：候选覆盖目标 ≥ 50% 的像素，且候选面积 ≤ 目标外接框面积的 4 倍，阈值与任务说明一致。另外补充了“去掉面积上限”的覆盖率，用来区分两种情况：一是找到了位置但候选区域太大，二是根本没找到。
- **纯度**：候选区域中，“真值变化 ∧ 检测器未预测”占比 ≥ 50% 的候选所占比例。
- **真值只用于评估**。所有候选都只由影像、检测器输出和 SAM3 产生。

## 各来源的实现

| 来源 | 实现（每项改动的理由在括号里） |
|---|---|
| A | MambaSCD 语义头（7 类 softmax，类 0 = 未变化）在类 1–6 内重新归一化后取 argmax，两期不同的像素取 8 连通域。分数 = 区域内 1 − Σ p1·p2 的均值。SYSU 的 SChanger 没有语义头，**不做 A**。 |
| B | SAM3 文本提示：低矮植被用 grass / farmland，地表用 bare ground / road / parking lot，另有 tree、water、building、sports field，同类多个提示取最大。像素类别取最高置信类，置信度 < 0.1 记为未标注。两期都有标注且类别不同处取连通域，分数 = 两期置信度乘积的均值。（SAM3 默认只保留得分 > 0.5 的实例，对草地、裸地这类成片地物几乎不出结果，冒烟测试中 92% 的像素没有类别，所以 B 用的实例阈值降到 0.1。冒烟测试的 3 张图上，B 得到的类别与真值类别在变化像素上的一致率只有 21–71%，这是一张粗糙的地物图。） |
| C | SAM3 "building" 实例（得分 ≥ 0.5），两期按 IoU 匹配。C1：最佳 IoU < 0.5 的实例（t2 视为新建，t1 视为拆除），分数 = 1 − IoU。C2：匹配上的建筑对，分数 = 实例内两期 SAM3 特征余弦距离的均值，只保留全数据集前 20%（阈值按分数分布定，不用真值）。“实例内特征距离”用 patch 级余弦距离的区域均值代替“先池化再算距离”，以免存储全部特征图。 |
| D | SAM3 视觉特征（256 维，72×72 patch）两期余弦距离，双线性上采样到原图，按图内分位数（前 5% / 10% / 20%）阈值化后取连通域。 |
| E | 检测器概率 > 0.9 的 patch 连通域作为样例，每个样例取两期特征拼接向量的均值。全图每个 patch 计算与最近样例的余弦相似度，取图内前 10% 的连通域。SECOND 有 1% 的图、SYSU 有 9% 的图没有样例，这些图跳过。 |
| F | 64 px 网格，步长 32。 |
| G | 检测器概率 > 0.05 / 0.1 / 0.2 的连通域（被 0.5 预测覆盖超过一半的已去掉）。 |

## 结论

1. **没有一个来源能单独覆盖大部分漏检。**
   - 除网格外，最好的单一来源是 B（SAM3 六类语义做差）：SECOND 覆盖 19.7% 的目标、25.8% 的像素；SYSU 为 34.7% / 39.8%。
   - A–E 主变体的并集：SECOND 37.1%，SYSU 49.7%；再加 G（阈值 0.1）后为 42.1% 和 57.0%。
   - 网格 F 覆盖最多（29.9% / 51.8%），但每图约 190 个候选，盖住 83–90% 的图像，等于没有筛选。
2. **很多漏检“位置找到了，但候选区域太大”。** 去掉面积上限后，A、B、G0.05 在 SECOND 上的覆盖率升到 39–44%，F 升到 93%。语义做差和降阈值产生的是大片连通区域，往往把漏检目标和周围的伪变化连在一起。下一步，提高候选粒度（例如在大区域内按实例或超像素切分）比换来源更值得做。
3. **候选纯度极低（2.5–20%）**：80% 以上的候选是伪变化。召回侧能否成立，主要取决于确认环节（实验 4b）。
4. **按变化类型，最有用的来源不同。**
   - 改建（建筑→建筑）几乎只有 C 能找到：目标 37%、像素 66%，而 A、B、D 只有 1–7%。
   - 其他类型（新建、拆除、植被、地表↔植被、水体）以 B 为最好（19–22%）。
   - 编码器特征差 D 和同类检索 E 都很弱：E 只有 1–2%，图内样例对漏检几乎没有代表性。
5. **检测器的低概率仍是最省的召回线索。** G（阈值 0.05）在每图只取前 10 个候选时，SECOND 覆盖 13.9%，高于其他任何来源（B 为 6.7%）。SYSU 上 G0.05 每图只有 1.1 个候选，就能覆盖 28.7%。这与实验 1 的“降阈值整体 F1 下降”并不矛盾：作为排序线索它有用，直接用阈值并入就有害。
6. **小目标仍很难覆盖**：SECOND 上 < 100 px 的目标，B 只覆盖 7%，F 为 0%。

**选给实验 4b 的两个来源：B 与 G0.05。** B 是覆盖率最高的非网格来源；G0.05 的“覆盖率–候选数”折中最好，而且在两个数据集上都适用。改建这一类应另外保留 C，但 C 的覆盖总量较小，没有放进 4b。
